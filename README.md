# 🖥️ Computer Hardware Fundamentals

## About This Project
This project contains my learning notes about computer hardware components, maintenance, and troubleshooting.

## 1. Main Computer Components
- CPU – Central Processing Unit
- RAM – Random Access Memory
- Motherboard
- HDD – Hard Disk Drive
- SSD – Solid State Drive
- Power Supply Unit (PSU)
- GPU – Graphics Processing Unit

## 2. Hardware Functions

| Component | Function |
|---|---|
| CPU | Processes instructions |
| RAM | Temporary working memory |
| Motherboard | Connects computer components |
| HDD | Stores data magnetically |
| SSD | Stores data using flash memory |
| PSU | Supplies electrical power |
| GPU | Processes graphics |

## 3. BIOS and UEFI
- BIOS: Basic Input/Output System
- UEFI: Modern firmware interface used to initialize hardware and start the operating system.

## 4. Basic Hardware Troubleshooting
- Check power connections.
- Check display cables.
- Inspect RAM installation.
- Check storage availability.
- Keep cooling vents clean.
- Check hardware temperatures.

## 5. Computer Maintenance
- Clean dust from vents regularly.
- Keep software and drivers updated.
- Maintain sufficient storage space.
- Use proper shutdown procedures.
- Back up important files.
